# Model Overview

## 1. System description

The current model represents a free-swimming underwater robot as a rigid central body with two prescribed oscillating appendages.  The default parameters instantiate a manta-like biomimetic swimmer, but the software architecture is written in generic underwater-robot terms.

The model focuses on:

1. rigid-body translational and rotational dynamics;
2. body-frame velocity propagation to appendage root frames;
3. spanwise oscillating-appendage kinematics;
4. local slice velocity calculation;
5. Morison-type hydrodynamic drag force integration;
6. quaternion attitude integration.

## 2. State definition

The state vector is:

```text
x = [p_wb, q_wxyz, v_b, omega_b] ∈ R^13
```

where `q_wxyz` follows `[w, x, y, z]` convention.

## 3. Gait definition

The generic oscillating-fin gait is parameterized by:

- `omega_left`, `omega_right`: appendage oscillation angular frequencies;
- `beta_left`, `beta_right`: spanwise phase offsets;
- `yaw_amplitude`: root yaw/bending amplitude;
- `yaw_phase`: gait phase bias.

The prescribed root appendage angles are generated by `OscillatingFinRobot.set_gait_at_time`.

## 4. Appendage kinematics

For each spanwise coordinate `s`, the model computes two linkage angles from the original four-bar-inspired mechanism.  The generic API is:

```python
theta_s, theta_l, P1, P2 = model.appendage_link_angles(s, t, left=True)
```

The midpoint velocities of two appendage link segments are obtained by propagating body velocities through root bending rotations and numerically differentiating local link angles.

## 5. Hydrodynamics

The appendage force model projects local midpoint velocity onto an estimated normal direction, then applies quadratic drag:

```text
dF ≈ -0.5 rho Cn ||Vn|| Vn A_slice
```

The local force and moment are integrated along the appendage span using fixed Gaussian quadrature.

## 6. Rigid-body dynamics

The body acceleration is assembled from:

- left and right appendage hydrodynamic wrench;
- dissipative body drag;
- angular damping;
- weak gravity/buoyancy offset moment;
- body-frame Coriolis terms.

## 7. Generalization path

This repository is intended to become a broader underwater robotics library.  Future models can reuse:

- the 13-state rigid-body convention;
- quaternion and rotation utilities;
- simulation and plotting wrappers;
- hydrodynamic wrench aggregation patterns;
- controller-compatible `state_derivative(t, x, input)` interfaces.

Possible extensions include thruster-driven AUVs, multi-fin swimmers, tail-actuated fish-like robots, and controller examples for trajectory tracking.
